# Meera Tamboli — Premium Portfolio

Static GitHub Pages portfolio. Upload the three files in this folder to the root of your repository.

## GitHub Pages
Settings → Pages → Deploy from branch → `main` → `/ (root)` → Save.

## Edit
Main content: `index.html`
Design: `style.css`
Interactions: `script.js`

Replace the email/social links in `index.html` with your preferred contact details if needed.
